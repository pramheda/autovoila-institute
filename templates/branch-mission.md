# Branch mission

Replace this file with a dense mission written by the parent.

Explain:

- why this branch exists;
- the scientific question;
- current evidence and beliefs;
- strongest live alternatives;
- relevant artifacts;
- what must remain independent;
- what result would materially update the parent;
- available tools and constraints;
- and when to report upward or ask for human attention.

This is not a form. Add, remove, or reorganise content to suit the branch.
