# Mutable research world

This directory is the institute's canonical working object.

- `programme-state.md`: compressed current research understanding.
- `human-inbox.md`: decision-ready requests to the human.
- `human-decisions.md`: durable human instructions and their interpretation.
- `institute-log.md`: material organisational history.
- `branches/`: independent research branches.
- `confirmations/`: frozen claim tests.
- `artifacts/`: cross-branch artifacts.
- `exports/`: papers, briefs, websites, and other generated views.

Summaries are not canonical evidence. Preserve raw sources underneath.
